● Не сохранено
Как пользоваться: правьте поля, нажмите «Скачать tasks.js» — и замените файл рядом с index.html (на компьютере или в репозитории сайта). После этого изменения увидят все игроки. Механику задания можно менять — у каждого файла и филиала есть поле «Тип задания» (тест / сопоставление / порядок). Не меняйте поле «ID» — по нему работает прогресс игроков.
Сайт на GitHub Pages? Сохранить файл прямо со страницы нельзя: скачайте tasks.js и загрузите его в репозиторий (GitHub → Add file → Upload files → заменить tasks.js). Через минуту сайт обновится у всех. Черновик правок пока хранится только в этом браузере — кнопка «↻ Перечитать tasks.js» его сбрасывает.
